WebSocket vs Webhook

WebSocket 模式 默认

  • 机器人主动连接 QQ 网关，维持长连接
  • 无需公网 IP 或域名
  • 消息收发延迟低（~100ms）
  • 群聊主动消息：受限，需要群内有用户先 @机器人
  • 频道消息：支持主动推送
  • 适合：开发调试、小规模部署

Webhook 回调模式 当前

  • QQ 服务器主动 POST 事件到你的回调地址
  • 需要公网可达的 URL（域名 + HTTPS）
  • 消息收发延迟取决于网络（~200-500ms）
  • 群聊主动消息：同样受限，需群内用户先 @机器人
  • 可配合 Cloudflare Tunnel 免域名使用
  • 适合：生产环境、多机器人管理

关于群聊主动消息：QQ 群聊机器人的主动推送能力受平台限制，两种模式下都需要群内用户先 @机器人 后，机器人才能在该群发送消息。这不是代码问题，而是 QQ 开放平台对群聊机器人的策略限制。如需真正的主动推送，建议使用频道机器人或第三方推送服务（Server酱、PushPlus 等）。
